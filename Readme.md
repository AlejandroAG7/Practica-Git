## Practica de Git
# Estructura arquitectura monolítica y microservicios

- Una arquitectura monolitica es cuando por ejemplo un codigo esta ecrito todo en un mismo bloque o un programa entero 

- Los microservidores podemos decir que son diferentes espacios donde cada uno trabaja algo diferente lo que nos veneficia a la hora de que si uno falla no entorpezca a los otros espacios y que puedan continuar trabajando 

# Diferencia entre fronted y backend. 

- El fronted es la parte por ejemplo visible de una aplicacion para el usuario mientras que el backend es la parte que no es visble para el usuario es decir todo el proceso de formacion, como se estructura etc ..
